## Reporting a Vulnerability

We take the security of `agent-2pc` seriously. If you discover a security vulnerability (such as a WAL checksum bypass, scratch isolation leak, or untrusted path traversal during atomic file promotions), please report it responsibly:

1. **Email:** Contact [ronitgupta138@gmail.com](mailto:ronitgupta138@gmail.com) directly with details, reproduction steps, and potential exploit vectors.
2. **GitHub Security Advisory:** Alternatively, submit a private advisory via [GitHub Security Advisories](https://github.com/ronitgupta138/agent-2pc/security/advisories/new).

Please **do not** open public GitHub issues for security vulnerabilities. We will acknowledge your report within 48 hours and work on a coordinated patch and release.
